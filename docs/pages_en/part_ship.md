# Part 6: Polish and release {#part_ship}

**Level: intermediate.** Read this first: your game is already playable (you finished @ref part_world), and you should have menus from @ref ui. This
part turns a level into a game: a main menu, pause, saving progress, the player's settings and a release build.

## Follow this order

| Order | Page | What you get |
|---|---|---|
| 1 | @subpage scenes | Split the game into menu, playing, pause, game over; fade transitions |
| 2 | @subpage window_files | The window, fullscreen, screenshots, asset paths, the save-game folder |
| 3 | @subpage json | Read and write JSON: save games and config files |
| 4 | @subpage settings | Per-channel volume, key rebinding, gamepad rumble, saving the player's settings |
| 5 | @subpage samples | Read a complete sample game and package a release |

Read @ref samples as a **final exam**: the sample game uses almost every page before it.

## What to do next

@ref part_advanced if the game needs graphics effects, generated maps or performance measurement.
