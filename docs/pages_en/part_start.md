# Part 1: Getting started {#part_start}

**Level: beginner.** After this part you will have a working build environment, a first njin program and a character
that runs or jumps on a map. You do not need to know anything about njin beforehand.

## Follow this order

| Step | Page | What you get |
|---|---|---|
| 0 | @subpage learn | 13 foundation lessons on C, C++, CMake, shaders and game patterns. If it is all new, read them first; if you know them, skip |
| 1 | @subpage setup | Install a compiler, CMake and Ninja on Windows, Linux and macOS |
| 2 | @subpage getting_started | Build njin, run the sample game, write your first program |
| 3 | @subpage first_jump | Platformer: a character that runs and jumps on a map, in 50 lines |
| 3 | @subpage first_walk | Top-down: a character that walks in 8 directions and dashes on a map, in 50 lines |

Step 3: pick one of the two according to the genre you plan to make; doing both is quick too, since each lesson is under 50 lines.

## What to do next

Go to @ref part_core to understand why the lessons above work: modules, systems, entities, components. If you only want to look up
one specific task, use @ref cheatsheet.
